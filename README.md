# Kassenbuch – Installation auf Android

Die App besteht aus diesen Dateien: `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`.

## 1. Online stellen (einmalig, kostenlos)
Android installiert Web-Apps nur von einer HTTPS-Adresse. Am einfachsten mit GitHub Pages:
1. Auf github.com ein neues öffentliches Repository anlegen, z. B. `kassenbuch`.
2. „Add file → Upload files“ und alle sechs Dateien hochladen.
3. Settings → Pages → Branch `main`, Ordner `/ (root)` → Save.
4. Nach etwa einer Minute ist die App unter `https://<dein-name>.github.io/kassenbuch/` erreichbar.

Veröffentlicht werden nur die App-Dateien. Deine Belege und dein API-Schlüssel bleiben auf dem Handy.

## 2. Auf dem Handy installieren
1. Die Adresse in Chrome öffnen.
2. Menü (⋮) → „App installieren“ bzw. „Zum Startbildschirm hinzufügen“.
3. Die App erscheint wie eine normale App mit eigenem Symbol.

## 3. Einrichten
1. API-Schlüssel auf console.anthropic.com erstellen und Guthaben aufladen (z. B. 5 €).
2. In der App: Einstellungen → Schlüssel eintragen → „Verbindung testen“.
3. Unter „Budgets“ die Monatsbudgets festlegen.

## Nutzung
- Kamera-Knopf unten → „Foto aufnehmen“ → Ergebnis prüfen → Speichern.
- Regelmäßig unter Einstellungen „Sicherung speichern“, denn die Daten liegen nur auf dem Handy.
